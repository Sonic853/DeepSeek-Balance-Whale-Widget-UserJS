# DeepSeek-Balance-Whale-Widget-UserJS

将 MeteorNOX 的 DSH 右下角小鲸鱼挂件移植为独立用户脚本。保留原角色与模块化气泡编辑器，直接通过 **HTTPSend 2** 查询 DeepSeek API 余额，配置和账本保存在用户脚本管理器中。

**运行范围：所有 HTTP/HTTPS 网站的顶层页面。默认只在 `deepseek.com` 及其子域名显示挂件，其他网站需手动开启。**

## 安装和使用

1. 打开 [DeepSeek-Balance-Whale-Widget.user.js](DeepSeek-Balance-Whale-Widget.user.js)，将完整内容粘贴到 Tampermonkey 的新建脚本编辑器，保存。此仓库提供的是构建成品，不需要在浏览器中运行 Node.js。
2. 打开或刷新 DeepSeek 页面，右下角会出现小鲸鱼。
3. 通过用户脚本管理器菜单 **「设置 DeepSeek API 密钥」**，或挂件菜单 **「API 密钥 / 余额」**，粘贴 API key 并保存。密钥配置一次后在此用户脚本的所有网站间共享。
4. 点击角色显示气泡；拖动角色改变位置。菜单中可调整大小、音效、吸附边界、预警、预算、角色和气泡内容。
5. 管理器菜单和挂件菜单均提供三个显示开关，修改立即生效并同步到已打开的标签页。关闭菜单按钮后，桌面端可右键角色，触屏端可长按约 1.5 秒打开菜单。

首次安装会由脚本管理器下载 `@require` 和 `@resource`。若这些资源未下载成功，重新保存或安装脚本，让管理器完成下载。

### 显示开关

| 开关 | 默认 | 生效范围 |
| --- | --- | --- |
| 全网站显示 | 关闭 | 所有 HTTP/HTTPS 网站 |
| 本站显示 | 关闭 | 当前主机名；例如 `example.com` 与 `www.example.com` 分别设置 |
| DeepSeek 网站显示 | 开启 | `deepseek.com` 及其全部子域名 |

三个开关独立保存，任一开启且适用于当前网站时显示。例如关闭全网站显示后，DeepSeek 默认仍显示；普通网站可以单独开启本站显示。要隐藏挂件，需要关闭当前所有适用的开关，挂件菜单会列出当前显示来源。

未显示挂件的网站仍保留脚本管理器中的三个开关和诊断菜单。此时不创建挂件、读取图片/音频资源或请求余额；关闭显示会移除 DOM、停止音频、取消请求并清理挂件计时器和事件。启用后才出现密钥设置、刷新和导出菜单。新版使用独立显示设置，之前的 `hidden:主机名` 设置不再参与判断。版本保持 1.0.0，尚未发布。

### 菜单按钮点击与透明区域

鼠标移入角色图片范围或菜单按钮附近即可显示按钮；经过图片的透明部分时保持显示，离开后隐藏。此范围只用于显示按钮，透明图片区域仍允许点击下方网页。关闭的菜单和气泡继续禁用点击与键盘焦点。

回归检查覆盖沿透明区域移动到按钮、按钮中心及边缘九点命中、重复开关、镜像/窄视口，以及周边隐藏控件的点击命中扫描。

### Edge / Tampermonkey 音效播放

真实扩展环境返回的 MP3 资源带有 `data:application;base64,…` 类型，Edge 报 `Unable to load URL due to content type`。现在按资源文件名补齐 `audio/mpeg` / `audio/wav`，保留音频数据原样。

同时修复按下槽留空时松开音效不能重复播放的问题；切换音效组会停止旧音频和延迟播放。音量为 0 或已有配置 `sound:false` 时保持静音，首次安装默认静音。要启用声音，请在挂件菜单把「音量」调到大于 0，再点击角色。

升级时用本目录成品覆盖原脚本并保存，刷新已打开的 DeepSeek 页面。菜单「查看小鲸鱼运行状态」增加最近的音频播放状态与错误，便于检查资源加载或浏览器声音权限。

### 关闭菜单不再拦截网页点击

修复透明菜单及其子按钮、输入框仍可点击的问题。关闭菜单时立即禁用整个子树的鼠标命中和键盘焦点，打开后恢复；未显示的菜单按钮、关闭气泡中的链接也停止拦截点击。保留菜单几何尺寸用于定位。

浏览器回归覆盖初始关闭、按钮关闭、点击外部关闭、重新打开、Tab/直接聚焦，以及关闭区域下方的真实网页按钮能否收到点击。

### 组件未显示时

已修复 Tampermonkey 拼接脚本时的入口问题：已发布 HTTPSend 的末尾条件赋值没有分号，主脚本以 `(() => { ... })()` 开头时，会被解析为该条件分支的一部分，导致整个挂件静默跳过。现在构建产物在自执行函数前明确加 `;`，可继续使用原来的已发布 `@require` 地址。

脚本提供启动阶段诊断。打开脚本菜单 **「查看小鲸鱼运行状态」**，可查看启动阶段、HTTPSend 是否存在、资源数量、角色图片是否加载、是否隐藏及错误文本；报告不包含密钥或账本。

若此菜单也不存在，在 F12 Console 中刷新页面并查找 `[DeepSeek Whale] 用户脚本入口已执行`：没有这条日志表示尚未进入脚本正文，需要检查管理器执行权限、脚本启用状态和外部依赖下载。已进入但初始化失败时，页面右下角会显示错误提示，诊断菜单仍保留。

### 数据含义

- **余额**来自配置的 API 账户。DeepSeek 内置接口为官方 `GET /user/balance`，认证方式为 `Bearer API_KEY`，优先展示 CNY，只有 USD 时展示 USD。[官方接口文档](https://api-docs.deepseek.com/api/get-user-balance/)
- 网页聊天登录状态与 API key 分开；这个余额不表示网页会员、聊天次数或网页模型额度。
- **今日已用**按北京时间、同一账户当天相邻余额样本的下降额累计；首次读取、跨日首个样本、换密钥或换币种只建立基准。充值不会被当成消费。
- 这是一份余额观测账本，无法确定消费属于哪条对话或哪个模型。采样之间同时发生充值和消费时，净余额变化不能恢复完整消费；跨日间隔的消费也不分摊到某天。
- 余额默认每 60 秒刷新，手动刷新跳过 25 秒缓存；隐藏挂件或标签页后暂停定时刷新，重新显示时刷新。
- 未配置 key 时，挂件仍可作为桌宠使用，不向余额接口发请求。默认关闭声音、余额预警和预算提醒，需要时在菜单启用。

## 自定义余额接口

在「小鲸鱼记账」的模型列表中新增「自定义 HTTP」，填写接口和字段路径。例如接口返回：

```json
{ "account": { "remaining": "12.50" } }
```

将余额 URL 设为你的 HTTPS 接口，认证模板为 `Bearer {key}`，剩余金额字段为 `account.remaining`，乘数为 `1`。也支持 `balance_infos[0].total_balance` 形式的数组路径，以及「总额 − 已用」或单独已用接口。

`@connect *` 用于用户自己配置的跨域余额接口。默认只向 `api.deepseek.com` 查询余额；不会自动连接原版其它厂商模板。自定义配置最多 20 项。

## 存储和导出

GM 存储统一使用前缀 `deepseek-whale-userjs:v1:`。API key 独立存放，不回填到设置窗口，不写入网页 localStorage，不包含在记录导出中。角色、气泡、账本和 key 在同一脚本的所有网站间共享；位置和本站显示按主机名分别保存，全网站/DeepSeek 显示开关全局共享。

余额下降明细保留最近 90 天、最多 20,000 条；每日总额保留 365 天。更换 key、接口配置或币种时，旧账本单独存档，导出菜单也包含这些存档。超出当前账本保留期的数据会裁剪，需长期留存时请定期导出。

自定义资源存为 data URL。服务层限制：角色单个 20 MB，气泡图片/音频单个 8 MB，每类上传最多 100 个，气泡配置最多 512 KB；管理器自身的存储限制仍然适用。

## 源码结构与构建

```text
DeepSeek-Balance-Whale-Widget.user.js   可安装成品
src/main.js                          页面入口、Shadow DOM、事件及生命周期
src/service.js                       GM 存储与原版接口适配、HTTPSend 请求
src/core.js                          余额解析、账本、北京时间及默认配置
vendor/whale-widget.js                原版前端原始副本
scripts/build.mjs                     AST 提取、移植补丁、esbuild 打包
assets/                              原版资源本地副本，供测试及来源留档
tests/                               单元测试、浏览器联调
docs/COMPONENT_ANALYSIS.md            组件详细分析与移植决策
```

PNG、GIF、MP3 和 WAV 素材使用 Git LFS 管理。安装 Git LFS 后，首次克隆仓库时准备素材：

```powershell
git lfs install --local
git lfs pull
```

使用 Node.js 20+：

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd test
npm.cmd run test:browser
npm.cmd run test:audio
```

浏览器测试默认使用 Windows Edge；其它环境可将 `WHALE_BROWSER` 设置为 Chromium/Chrome/Edge 可执行文件绝对路径。截图和报告写入 `test-results/`。

另有真实扩展测试：将 `WHALE_TAMPERMONKEY` 设为已安装 Tampermonkey 的版本目录（包含 `manifest.json`），运行 `npm.cmd run test:extension`。测试创建空白 Edge 配置，安装成品，实际下载 `@require`/`@resource` 并打开 `https://www.deepseek.com/en/`，不读取原用户的脚本或密钥。测试配置、截图和报告留在 `test-results/`。

编辑 `src/main.js`、`src/service.js`、`src/core.js`、`src/audio.js` 或构建脚本；不要手改构建产物和 `src/widget.generated.js`。构建过程不联网下载上游源码，补丁目标不匹配时会报错，便于检查上游升级影响。
